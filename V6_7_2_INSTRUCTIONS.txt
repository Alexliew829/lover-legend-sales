Lover Legend Sales V6.7.2

基准：
- 页面结构、每个页面显示及排版完全以 V6.6.1 为基础。
- 没有采用 V6.7.1 错误重复出现的“本年度累计”结构。

唯一功能变化：
- Fair 本月营业额少于 RM50,000：佣金 6%
- RM50,000 至 RM99,999.99：佣金 7%
- RM100,000 或以上：佣金 8%
- 未达 RM50,000：红字“加油，达到 RM50,000 就 7%”
- 已达 RM50,000 但未达 RM100,000：红字“加油，达到 RM100,000 就 8%”
- 达到 RM100,000 后不显示提示

版本：
- 网页、version.json、Service Worker 缓存统一为 V6.7.2

安装：
1. 覆盖上传整个 GitHub 网站文件。
2. Apps Script 不需要修改。
3. 等 GitHub Pages 部署完成。
4. 电脑第一次按 Ctrl + F5。
5. 手机完全关闭 App 后重新打开。
