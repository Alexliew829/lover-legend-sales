Lover Legend Sales V6.7.1

更新：
- Fair 本月总营业额少于 RM50,000：佣金 6%
- RM50,000 至 RM99,999.99：佣金 7%
- RM100,000 或以上：佣金 8%
- 少于 RM50,000：显示“加油，达到 RM50,000 就 7%”
- 少于 RM100,000 且已达到 RM50,000：显示“加油，达到 RM100,000 就 8%”
- 达到 RM100,000 后不显示提示
- 网页、version.json、Service Worker 缓存名称统一更新为 V6.7.1

安装：
1. 覆盖上传整个 GitHub 网站文件。
2. Apps Script 不需要修改。
3. 等 GitHub Pages 完成部署。
4. 电脑第一次按 Ctrl + F5。
5. 手机完全关闭 App 后重新打开。
