Lover Legend Sales V6.8

新增：
- More 页面可修改三档 Fair 佣金：
  1. RM50,000 以下
  2. RM50,000 以上
  3. RM100,000 以上
- 可储存佣金设置
- 可恢复默认值 6% / 7% / 8%
- Home 页面佣金金额、标题与红色提示自动跟随设置
- 设置储存在当前设备的 localStorage，不影响 Google Sheet 和营业资料

注意：
- 不同手机或电脑的佣金设置彼此独立。
- 删除 App、清除浏览器网站资料后会恢复默认值。

安装：
1. 覆盖上传整个 GitHub 网站文件。
2. Apps Script 不需要修改。
3. 等 GitHub Pages 部署完成。
4. 电脑第一次按 Ctrl + F5。
5. 手机完全关闭 App 后重新打开。
